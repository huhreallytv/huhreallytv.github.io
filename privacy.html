Privacy Policy

Last updated: October 7, 2026

"Huh Really Stats" is an internal tool used only by the owners of the YouTube channel Huh, Really? (@HuhReallyTV). It is not offered to the public.

What it accesses

With the channel owner's permission, the tool reads the channel's own YouTube statistics (views, watch time, subscribers, traffic sources and audience retention) through the YouTube Data API and the YouTube Analytics API, using read-only access. It cannot upload, edit or delete anything.

How the data is used and stored

The statistics are saved on the channel owner's own computer and used only to understand and improve the channel's videos. The data is not sold, shared with third parties, or used for advertising. The tool does not access data of any other YouTube user.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; the locally stored statistics can be deleted at any time.
